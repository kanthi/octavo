# Getting started

```bash
cargo new hello
cd hello
cargo run
```

Cargo wrote this for you in `src/main.rs`:

```rust
fn main() {
    println!("Hello, world!");
}
```

| Command | What it does |
|---|---|
| `cargo run` | Build and run |
| `cargo check` | Type-check without building |
| `cargo test` | Run the tests |
