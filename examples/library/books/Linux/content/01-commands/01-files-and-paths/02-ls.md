# ls

`ls` lists what is in a directory.

```bash
ls -l      # long form: permissions, owner, size, date
ls -a      # include hidden files
ls -lhS    # largest first, sizes in K/M/G
```

## Reading the long form

```text
-rw-r--r--  1 k19g  staff  1.2K Nov 16 10:02 notes.md
```

- [x] First character: `-` file, `d` directory, `l` link
- [x] Next nine: read/write/execute for owner, group, others
- [ ] The rest: links, owner, group, size, date, name

> [!WARNING]
> Do not parse `ls` output in scripts. File names can contain spaces and newlines. Use a glob or `find` instead.
