# IP

IP delivers packets between networks. Routers read the destination address and pass the packet one hop closer.

## Header fields worth knowing

- **TTL:** drops by one at each router. At zero the packet is discarded.
- **Protocol:** what is inside, such as 6 for TCP and 1 for [ICMP](02-icmp.md).

How addresses are grouped is covered in [subnets](../../02-addressing/01-subnets.md).
