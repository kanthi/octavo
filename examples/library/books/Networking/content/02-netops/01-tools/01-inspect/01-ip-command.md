# ip

The `ip` command shows and changes links, addresses and routes.

```bash
ip link          # interfaces
ip addr          # addresses
ip route         # routing table
ip neigh         # ARP table
```

Background for each: [Ethernet](../../../01-foundations/01-layers/01-link/01-ethernet.md), [IP](../../../01-foundations/01-layers/02-internet/01-ip.md).
